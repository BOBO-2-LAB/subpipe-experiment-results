## 1. 管道语义分割

### 1.1 早期结构、种子和数据对照

早期实验使用 SubPipe-mini 的518帧训练和129帧验证，按历史协议取验证最佳检查点。M11 为无小波 EFSNet＋深度可分离解码器。种子42下，M11 的管道 IoU 为68.34%，参数0.476M，历史计时算量2.49 GFLOPs。普通解码器基准为67.07%、1.059M、9.63 GFLOPs。M6 的单次管道 IoU 达68.67%，但参数为2.014M。

|固定划分，种子42/43/44|三次 mIoU 均值±样本标准差|
|---|---:|
|普通卷积基准|79.69% ± 0.31%|
|M6，注意力小波＋大核深度卷积|79.42% ± 0.93%|
|M11，深度可分离解码器|80.20% ± 0.14%|
|M12，进一步缩小解码器宽度|79.57% ± 0.60%|

历史 P1–P6 评估了 EFSNet 和 Swin 单支路、双编码器拼接、跨注意力、CBAM 以及轻量解码器。原论文所述的逐级提升在本地划分上未复现。V 系列试过边界加权、光度增广强弱和 FixMatch。其中基准两种子 mIoU 为80.24%，FixMatch 为78.90%。外观切分中，随机划分84.28%，蓝调到绿调的跨外观对照72.50%，强颜色抖动后80.56%。这些评估的样本与模型版本见索引，跨外观结果属于本地数据切分。

证据：`mono/FINDINGS.md` 第1–13节，`mono/runs_ablation`、`mono/runs_seed43`、`mono/runs_seed44`、`mono/runs_paper`、`mono/runs_scene`。

### 1.2 普通 Haar 小波与解码器的五折对照

647帧按时间划分为5个连续留出块，隔离2秒，固定种子42，统一取第60轮，合计20次训练。A0去掉小波和相应融合，A1-S与A1-D只改变解码卷积。A3包含注意力小波、门控和软阈值。

|组别|参数|管道 IoU|管道召回|边界 F1|
|---|---:|---:|---:|---:|
|A0 无小波＋深度可分离卷积|476,342|71.97% ± 4.71%|87.57% ± 4.12%|29.22% ± 2.73%|
|A1-S 普通小波＋普通卷积|1,526,582|72.30% ± 4.84%|88.04% ± 3.97%|29.78% ± 3.60%|
|A1-D 普通小波＋深度可分离卷积|943,798|72.26% ± 4.52%|87.67% ± 4.31%|29.67% ± 3.52%|
|A3 注意力小波＋深度可分离卷积|1,321,782|72.02% ± 4.42%|87.26% ± 4.72%|29.65% ± 3.69%|

A1-D比A1-S少38.18%参数，管道 IoU 低0.04个百分点。A1-D比A0的平均 IoU 高0.29个百分点，逐折为3升2降。A1-D比A3平均高0.23个百分点，5折方向一致，同时少28.60%参数。五折来自同一来源，结论限于本次结构取舍。

早期固定划分的 A0／普通小波／注意力小波管道 IoU 分别为68.27%／68.70%／67.59%。低边界对比度子集37帧的 IoU 为63.52%／63.69%／63.51%，召回为89.56%／93.01%／94.63%，边界 F1 为25.02%／23.85%／23.07%。子集结果显示召回与边界精度存在取舍。

证据：`mono/runs_review/m13_fivefold_20261030_v1`、`plain_standard_fivefold_20261031_v1`、`m13_wavelet_frontend_review_20261030_v1`。[五折逐折结果](五折与最终闭环明细.md)

## 2. 生物识别与联合架构

### 2.1 冻结共享编码器与独立生物编码器

早期 M11 管道通路冻结。SUIM 60轮实验中，使用管道的冻结编码器时，鱼 IoU 为38.06%，8类 mIoU 为43.16%。换用可训练的独立编码器后分别为63.68%和63.25%，冻结管道输出经逐位核查相同。后续在相同内部验证集的诊断口径中，原部署生物权重的鱼 IoU 为63.64%，含鱼命中79/99，无鱼候选14/52。早期冻结对照同时改变了共享方式和编码器可训练性。

### 2.2 无小波、普通小波、注意力小波消融

SUIM训练1,369张、内部验证153张，三组均60轮。候选条件为鱼概率>0.5、最大8连通域≥400像素。含鱼命中要求在99张足够大鱼体图中与真值重叠达到真值面积的10%。无鱼候选统计52张，两张小鱼图只计像素指标。

|组别|生物参数|鱼 IoU|含鱼命中|无鱼候选|前向中位数 / P95|
|---|---:|---:|---:|---:|---:|
|B0 无小波|390,652|60.47%|77/99|9/52|4.46 / 5.08 ms|
|B1 普通小波|475,260|60.84%|80/99|8/52|5.49 / 6.08 ms|
|B2 注意力小波|570,044|61.22%|76/99|9/52|5.88 / 6.53 ms|

B1的图像命中最多、无鱼候选最少。B2鱼像素IoU最高。B0最轻且前向最快。部署的原独立生物权重与B0架构相同，具体权重来自早期训练。两种小波生物权重的早期接入试验分别通过4/6，均在上升段含鱼和下降段含鱼遇到验收问题。

### 2.3 共同训练的共享编码器对照（2026-11-17）

两组保留 A1-D 管道头及8类生物头。共享组的一套 EFSNet 接收两项任务的梯度，独立组各用一套。两组初始输出相同，在固定的管道第0留出折及相同 SUIM 划分上配对微调5轮，统一取末轮。编码器均从该管道折的训练权重初始化，生物解码器沿用历史第60轮初始化。

|指标|独立编码器|共享编码器|
|---|---:|---:|
|管道 IoU|67.69%|44.97%|
|管道召回|84.33%|49.68%|
|管道边界 F1|25.82%|19.00%|
|鱼 IoU|47.33%|39.93%|
|含鱼命中|74/99|73/99|
|无鱼候选|23/52|31/52|
|总参数|1,334,450|997,758|
|同图双任务前向中位数 / P95|10.25 / 10.68 ms|6.86 / 7.64 ms|

在这次同初始化微调中，共享减少25.23%参数，管道和鱼 IoU 分别下降22.72和7.40个百分点。耗时为 RTX 4070 Laptop 上、FP32、384×384、单图两头前向。结果限于固定单种子、单个管道折及5轮微调协议。
